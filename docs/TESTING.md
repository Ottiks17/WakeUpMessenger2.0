## 9.2 Энергопотребление

Условия: экран выключен, Wi-Fi включён, 15 часов (18:00–09:00).

| Сценарий | Ожидаемый расход | Факт |
|---|---|---|
| Без сервиса | Базовый | |
| Сервис без нагрузки | +5% к базовому | |
| Сервис + 10 сообщений/час | +10% к базовому | |

Снятие: `adb shell dumpsys batterystats --charged com.wakemessenger`,
память: `adb shell dumpsys meminfo com.wakemessenger` (PSS ≤ 20 МБ).
