# Инструкция по настройке исключений энергосбережения

Общий принцип (п. 15 ТЗ): **приложение не должно быть ничем ограничено** —
ни батареей, ни автозапуском, ни фоновой активностью.

## Чистый Android / ТСД Atol

1. Настройки → Приложения → WakeUp Messenger → Батарея → **Без ограничений**.
2. Настройки → Приложения → WakeUp Messenger → Уведомления → включить все каналы.
3. Настройки → Батарея → Оптимизация батареи → Все приложения → WakeUp Messenger → **Не оптимизировать**.
4. Убедиться, что в разделе «Батарея» устройства отключён режим энергосбережения.

Быстрый путь: экран приложения «Настройка энергосбережения» → кнопка «Открыть настройки».

## Xiaomi / Redmi / POCO (MIUI)

1. Безопасность → Разрешения → **Автозапуск** → включить WakeUp Messenger.
2. Настройки → Приложения → WakeUp Messenger → Экономия батареи → **Без ограничений**.
3. Недавние приложения → удерживать карточку WakeUp Messenger → **замок** (защита от закрытия).

## Huawei / Honor

1. Настройки → Батарея → Запуск приложений → WakeUp Messenger → выключить «Автоматически»,
   включить все три: **Автозапуск**, **Косвенный запуск**, **Работа в фоне**.
2. Настройки → Батарея → Дополнительно → отключить «Закрывать приложения после блокировки».

## Oppo / Realme (ColorOS)

1. Настройки → Управление приложениями → WakeUp Messenger → **Разрешить автозапуск**.
2. Настройки → Батарея → Оптимизация энергопотребления → WakeUp Messenger → **Не оптимизировать**.
3. Настройки → Батарея → Больше → «Спящий режим приложений» → исключить.

## Vivo (Funtouch OS)

1. i Manager → Управление приложениями → Автозапуск → включить.
2. Настройки → Батарея → Высокое потребление в фоне → разрешить WakeUp Messenger.

## Проверка

1. Открыть приложение → Настройки → блок «Энергосбережение»: оба пункта должны быть «✓».
2. Погасить экран на 30 минут, отправить с сервера команду `ping` — в логе должен появиться
   приём команды и отправка `pong`.
3. Перезагрузить ТСД — уведомление сервиса должно появиться без запуска приложения вручную.

> На разных устройствах и версиях Android названия пунктов отличаются. Администратор обязан
> убедиться, что WakeUp Messenger добавлен во **все** исключения энергосбережения и автозапуска.
